# U0 manifest/FASTA work-unit composition fixture

This fixture binds one canonical `replicon x scale` work unit to an exact
single-record FASTA and the immutable U0 parameter bytes. The host boundary
verifies both SHA-256 identities and derives the 64-bit seed ledger prescribed
by ADR-0003. Sounio is the only producer of the complete v3 analytical row;
Julia independently returns to the parameter, manifest and FASTA bytes and
recomputes every draw, metric, summary and output byte.

This is deliberately one synthetic 16 bp work unit. It proves composition of
the already-validated manifest and multiscale analytical cores; it is not the
streaming chromosome executor, a RefSeq pilot, pilot-wide coverage, Parquet,
an execution receipt, or Gate U0 evidence.
