# Null-engine metamorphic fixture (Fase M4)

Frozen inputs for the metamorphic relations around both engineering null
engines (spec section 12.1 extension; executable specification, not a release
receipt). The canonical producer is the pinned official Sounio build of
`sounio/src/fasta_stream_fixture.sio` in `--pipeline` mode; no Sounio source
change is involved.

## Records (16 bp, one full window each, linear synthetic controls)

- `synthetic_homopolymer_a` / `synthetic_homopolymer_c`: every composition-
  preserving null draw is the source window. MR1/MR2: under both engines all
  null summaries are degenerate (mean == q025 == q975 == observed metric,
  mad == 0).
- `synthetic_alternating_ac`: strictly alternating; the dinucleotide
  multigraph has a unique fixed-endpoint Eulerian circuit, so it is identity
  under `dinucleotide_shuffle` (MR2) but randomizes under
  `mononucleotide_shuffle` (MR3).
- `synthetic_general_control` (`ACAGTCAGACAGTCAG`): branching dinucleotide
  multigraph (node A has out-edges to both C and G), so it randomizes under
  both engines (MR3); mononucleotide-preserving draws keep k=1 imbalance
  fields degenerate while k>=2 fields vary, and dinucleotide-preserving draws
  keep k=2 fields degenerate while order-dependent metrics vary.

MR4 (summary coherence) holds on every emitted window: each non-null null
block has `null_replicates_available == 8` and `q025 <= q975`.

## Files

- `nullmeta_fixture.fa` / `nullmeta_metadata.tsv`: frozen records and
  manifest association.
- `parameters_nullmeta_mono_k8.json` / `parameters_nullmeta_dinuc_k8.json`:
  canonical parameter artifacts (window 16, stride 16, k = 1..8, 8 null
  replicates) selecting each engine.
- `dinucleotide_seeds_nullmeta_k8.tsv`: frozen seed sidecar binding every
  window coordinate to the first 64 SHA-256 bits of
  `parameters_sha256:accession:window_start`; regenerated byte-exact inside
  `make contract` by `scripts/generate_dinucleotide_seed_sidecar.rb`.
- `SHA256SUMS`: checksum closure over the five frozen inputs, verified inside
  `make contract`.

## Execution

`make null-metamorphic-differential-fixture` (or
`scripts/run_null_metamorphic_differential.sh` with `SOUNIO_REPO` and, on
Apple Silicon, `SOUNIO_LIMA_INSTANCE`) runs each case as an
optimized/optimized/reference kernel triple (required byte-identical),
persists both JSONL artifacts, and then runs the independent Base-only Julia
validator `julia/scripts/validate_null_metamorphic.jl`, which recomputes
every line byte for byte at tolerance 0 and asserts MR1-MR4 explicitly over
the persisted producer output.
